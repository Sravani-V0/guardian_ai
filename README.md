# 🛡️ Guardian AI

Guardian AI is an AI-powered safety and assistance application designed to provide women with quick access to emergency support, location-based assistance, and intelligent safety features.

## 📌 Features

* 🚨 **Emergency Assistance** – Quickly access emergency support when needed.
* 📍 **Location Sharing** – Share the user's current location with trusted contacts.
* 👥 **Trusted Contacts** – Store and manage emergency contacts.
* 🤖 **AI Assistance** – Provides intelligent assistance for safety-related situations.
* 📱 **Cross-Platform Application** – Built using Flutter for Android, iOS, Web, Windows, macOS, and Linux.
* 🔔 **Safety Alerts** – Helps notify trusted contacts during emergency situations.

## 🛠️ Technologies Used

* **Flutter** – Mobile and cross-platform application development
* **Dart** – Application programming language
* **Python** – Backend/AI-related functionality
* **AI/ML** – Intelligent safety assistance
* **HTML/CSS/JavaScript** – Web support
* **Git & GitHub** – Version control and project management

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Sravani-V0/guardian_ai.git
```

### 2. Open the project

```bash
cd guardian_ai
```

### 3. Install Flutter dependencies

```bash
flutter pub get
```

### 4. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Flutter application

```bash
flutter run
```

## 🚀 How It Works

1. The user opens the Guardian AI application.
2. The application provides safety and assistance features.
3. The user can configure trusted emergency contacts.
4. During an emergency, the user can activate the appropriate safety feature.
5. Guardian AI can assist the user using AI-powered functionality.
6. Emergency information can be shared with trusted contacts when the required permissions and services are configured.

## 🎯 Objective

The main objective of Guardian AI is to create a smart and accessible safety solution that can help women respond quickly during emergency situations and provide useful AI-based assistance.
